# 广师大生存手册

> 一份由广师大学子共同维护的校园生活指南。

本手册灵感来源于[上海交通大学生存手册](https://survivesjtu.gitbook.io/survivesjtumanual)，针对广东技术师范大学（广师大）学子进行了本地化，同时也推荐未入学和高考填报志愿的朋友阅读。

项目维护者仅由本校学生组成，无任何利益关系，内容仅供参考。

## 快速开始

- **准新生**：从 [校园生活](guides/daily.md) 开始了解学校。
- **在校生**：查看 [学业指南](guides/exam.md) 和 [实用技巧](guides/tips.md)。
- **即将毕业/规划未来**：阅读 [职业与升学](career/job.md) 相关内容。
- **经验分享**：浏览 [博客文章](blog/echo-01.md)。
